# What is Commandr CLI?

Commandr CLI is a (CLI)[https://en.wikipedia.org/wiki/Command-line_interface] (or TUI) that aims to have the best user experience, customization and many features. It has a collection of different environment toolsfor different tasks across different (Operating System)[https://en.wikipedia.org/wiki/Operating_system]s.

## What is a TUI?

A (TUI)[https://en.wikipedia.org/wiki/Text-based_user_interface] is a Terminal user interface. We are currently making Commandr CLI into both a TUI and CLI. The Terminal User Interface idea came from freebuff or codebuff. As it is already a TUI, I was interested in making Commandr CLI itself a TUI for users that prefer TUIs over CLIs. 

### But why use TUIs?

Altough TUIs are not really needed for the primary user experience, It is good to have TUIs incase you are lazy or basically dont have a mouse. Since TUIs mainly rely on the keyboard, You can just use the Arrow Keys and `WASD` to contol or navigate through the TUI.
