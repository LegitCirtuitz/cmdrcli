# Introduction

Welcome to the **Official Commandr CLI** Documentation!

## What is Commandr CLI?

Commandr CLI is a CLI that currently has **around 1300** commands and is made by me, just a single developer on one huge project.  I am to add a total of around 15000+ Commands in total. It has many commands which are inspired by other Software Distribution Software, meaning that its an app that lets you to install apps. Such as  `pacman`. Pacman has a total of around 294 Packages from [MSYS2](https://msys2.org).
